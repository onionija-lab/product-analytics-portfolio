# Product Analytics Portfolio — Alex

Welcome to my Product Analytics portfolio.  
This repository showcases a collection of end‑to‑end analytical projects demonstrating my skills across:

- Statistical analysis & hypothesis testing  
- A/B testing & experimentation  
- SQL (including window functions and data mart design)  
- Python for data processing, feature engineering, and API work  
- Machine Learning for product use cases (regression, segmentation, churn)  
- BI dashboards (Tableau, PowerBI, Superset)  
- Product metrics (LTV, retention, funnels, unit economics)  
- Data storytelling, communication, and actionable recommendations  

Each project is structured to reflect real product analytics workflows and includes:

1. **Context** — what problem we are solving  
2. **Approach** — methodology, tools, and reasoning  
3. **Analysis** — code, queries, models, dashboards  
4. **Insights** — what the data tells us  
5. **Recommendations** — how this impacts the product  
6. **Next steps** — what could be improved or extended
